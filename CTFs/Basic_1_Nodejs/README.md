# CTF 1 -- Basic Node.js (Cookie Tampering)

A Node.js web application where the goal is to exploit an insecure Base64 session cookie to escalate privileges and retrieve the flag.

**Stack:** Node.js (Express), EJS templates

---

## Quick Start (Docker -- recommended)

Requires [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### 1. Generate credentials

```bash
cd CTFs/challenge-generation
node chgen_basic1.js abcd12 efgh34 ijkl56
```

This creates `CTFs/Basic_1_Nodejs/flags.json` and `CTFs/Basic_1_Nodejs/credentials.json`.

### 2. Start the application

```bash
cd CTFs/Basic_1_Nodejs
docker compose up --build
```

- Application: http://localhost:3000

Log in with any username and password from `credentials.json`.

To stop: `docker compose down`
To reset to a clean state: `docker compose down && docker compose up --build`

### Running without Docker (development)

Requires Node.js 16+.

```bash
cd CTFs/Basic_1_Nodejs
npm install

# Set paths for local development
export FLAGS_PATH=./flags.json
export CREDS_PATH=./credentials.json

node src/server.js
```

## CTF Flags

| Flag | Difficulty | Technique |
|------|-----------|-----------|
| 1 | Easy | Base64 cookie tampering, privilege escalation |

**Flag count:** 1 per user
**Flag format:** `durham{<hash>_<username>}`

---

## Features

- **User Authentication** -- Login with username/password (format: 4 letters + 2 digits, e.g. `abcd12`)
- **Home Page** -- Shows current user info from session cookie
- **Admin Flag Page** -- Requires admin role to access
- **Intentionally Insecure Cookie** -- Base64-encoded, unsigned, `httpOnly: false`

---

## CTF Integration

Flags and credentials are generated by `CTFs/challenge-generation/chgen_basic1.js` and mounted into the container at startup. The server reads `credentials.json` to seed user accounts and `flags.json` for per-user flag lookup.

- `flags.json` -- per-user flag values (HMAC-SHA256 deterministic)
- `credentials.json` -- per-user login passwords (randomly generated)

---

## Notes

- The session cookie is intentionally insecure (unsigned Base64 JSON) for learning purposes.
- Login rate limiting is enabled: 5 failed attempts triggers a temporary lockout.
- This CTF is designed as a beginner-level introduction to cookie tampering and privilege escalation.
