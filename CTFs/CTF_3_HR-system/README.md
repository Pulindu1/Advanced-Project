# CTF 3 — HR System

Multi-stage CTF covering SQL injection, API exploitation, and cryptography.

**Stack:** Laravel 11 (PHP 8.4), React + Vite, PostgreSQL 16

---

## Quick Start (Docker — recommended)

Requires [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### 1. Generate credentials

```bash
cd CTFs/challenge-generation
node chgen_ctf3.js abcd12 efgh34 ijkl56
```

This creates `CTFs/CTF_3_HR-system/flags.json` and `CTFs/CTF_3_HR-system/credentials.json`.

### 2. Start the application

```bash
cd CTFs/CTF_3_HR-system
docker compose up --build
```

Docker will:
1. Start a PostgreSQL 16 database
2. Build and start the Laravel backend (runs migrations + seeders automatically)
3. Build and start the React frontend

- Frontend: http://localhost:5174
- Backend API: http://localhost:8004
- PostgreSQL: localhost:5434 (for debugging)

To stop: `docker compose down`
To reset to a clean state (wipes the database): `docker compose down -v && docker compose up --build`

### Running without Docker (development)

Requires PHP 8.4, Composer, Node.js 18+, and a running PostgreSQL instance.

```bash
# 1. Start database only
docker compose up -d db

# 2. Backend
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --host=127.0.0.1 --port=8004

# 3. Frontend (new terminal)
cd frontend
npm install
npm run dev  # http://localhost:5174
```

## CTF Flags

| Flag | Difficulty | Technique |
|------|-----------|-----------|
| 1 | Easy | Discover hidden `/flag` route (path traversal hint in HTML comment) |
| 2 | Intermediate-Advanced | SQL injection + encryption key discovery + AES-256-CBC decryption |
| 3 | Easy | Authenticated API flag endpoint |

**Flag count:** 3 per user
**Flag format:** `durham-hr{<hash>_<username>}`

---

## Features

- **User Authentication** -- JWT-based login with per-user credentials
- **Employee Directory** -- Searchable list with SQL injection vulnerability
- **Debug API** -- Leaks credentials from credentials.json (intentionally vulnerable)
- **Hidden Flag Page** -- Discoverable via path traversal hints in source
- **Legacy Source Code** -- Encryption key exposed in client-side JS bundle
- **Per-user Bot Employees** -- Each player has a hidden `<username>-bot` employee with encrypted notes

---

## CTF Integration

Flags and credentials are generated by `CTFs/challenge-generation/chgen_ctf3.js` and mounted into the container at startup. The seeder reads `credentials.json` to create player accounts and bot employees, and `flags.json` for per-user flag values.

- `flags.json` -- per-user flag values (`flag_api` for the API endpoint, `flag_decrypt` for the decryption chain)
- `credentials.json` -- per-user login passwords + per-user bot entries with encrypted flag notes

---

## Vulnerabilities

- SQL injection in the employee search endpoint (bypassable filter)
- Debug API endpoint that leaks credentials
- Hidden route discoverable via path traversal
- Encryption key embedded in client-side code

**Note:** The `users` table uses secure bcrypt passwords. The `credentials` table stores plaintext passwords specifically for the SQL injection challenge.
